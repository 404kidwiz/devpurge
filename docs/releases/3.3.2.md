# DevPurge for Mac 3.3.2

The Mac app now uses the Zine paper-cut D icon, matching the website's pink,
lime and cobalt theme. All ten native icon representations are included.
Cleanup behavior is unchanged by this release.

## Download

- [DevPurge-3.3.2.dmg](https://github.com/404kidwiz/devpurge-releases/releases/download/v3.3.2/DevPurge-3.3.2.dmg)
- [SHA256SUMS.txt](https://github.com/404kidwiz/devpurge-releases/releases/download/v3.3.2/SHA256SUMS.txt)
- Apple Silicon (arm64), macOS 14 or later; version 3.3.2, build 3.
- Installer size: 2,132,367 bytes.

**Not yet notarized.** This build has an ad-hoc signature, not a Developer ID
signature. macOS may block first launch. The existing first-launch guidance is
System Settings → Privacy & Security → Open Anyway, only if you trust the download.

Download both files into the same directory and verify:

```sh
shasum -a 256 -c SHA256SUMS.txt
```

Expected SHA-256:

```text
34acdd0cb96aaf4f9dde5fc1fccf64ecf2badc7f430029363e093d6b12dcea0d  DevPurge-3.3.2.dmg
```

## Verification

The mounted installer passed DMG integrity and strict ad-hoc signature checks.
Its version, architecture, Applications shortcut and embedded icon were verified;
the release binary contains no development-license bypass. Native tests: 30
passed, one optional snapshot-export test skipped, zero failures. Native launch
and Apple notarization are not certified by these checks.

Release builds can use an isolated `APP_BUNDLE_PATH` without replacing or
registering a running local app. Signing failures now stop the local build.
The previous v3.3.1 release remains available for rollback.
